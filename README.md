# Lucas Campos

**Engenharia de Dados (em formação) | Python · Pandas · ETL · Git · Linux**

Construo pipelines de dados em Python: extraio dados de planilhas e
arquivos (CSV e XLSX), limpo e padronizo com Pandas e entrego conjuntos
de dados estruturados, prontos para uso.

## Com o que eu trabalho
- **Extração**: arquivos CSV e Excel
- **Transformação**: limpeza, remoção de duplicados, tratamento de tipos e junção de bases com Pandas
- **Entrega**: planilhas estruturadas, datasets e gráficos
- **Fluxo de trabalho**: Git, terminal Bash/Linux e projetos versionados no GitHub

## Projetos em destaque
- **[analise-estoque](https://github.com/lucasdevcampos/analise-estoque)**: classifica itens de estoque em Curva ABC (Pareto) a partir de planilhas, identificando quais produtos concentram a maior parte do valor

## Tecnologias
Python · Pandas · Git · Bash/Linux
